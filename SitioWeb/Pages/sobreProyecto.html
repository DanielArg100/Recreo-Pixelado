SOBRE EL PROYECTO

Proyecto escolar desarrollado para la Expotécnica de 6°3 de la E.E.S.T N°1 “Cecilia Berdichevsky”, en la materia Laboratorio de Diseño Web bajo la supervisión del Profesor Pablo Gareis. Recreo Pixelado es un juego de plataformas protagonizado por Bruno, un payaso triste, que transcurre entre las aulas, pasillos y patio de esa escuela.

OBJETIVO

Crear un sitio web funcional dedicado a Recreo Pixelado, combinando contenido informativo sobre el juego con una versión web jugable del mismo. El objetivo principal fue desarrollar una experiencia propia mediante un nivel personalizado y, después, seguir sumando mecánicas originales: el mate, sus efectos, el martillo mejorado y los enemigos con ocurrencias graciosas.

CARACTERÍSTICAS

• Sitio web completo con inicio, historia, controles y proyecto.

• Juego completamente jugable desde el navegador, en dos etapas.

• Mate: material de enemigos y bloques rotos (25%), hasta 2 guardados y tecla M para cebar.

• 13 efectos aleatorios con HUD de tiempo restante y estrellas en pantalla para el mareo y las alucinaciones.

• Martillo de alcance base 24 px, golpe simétrico y refuerzo temporal de +12 px.

• Enemigos goofy: goombas y koopas con ocurrencias aleatorias y globos de texto.

• Checkpoint, bandera, intentos renovables y HUD con retrato de Bruno.

• Funcionamiento directo en la web, sin instalar nada.

TECNOLOGÍAS UTILIZADAS

HTML5 — Estructura de las páginas.

CSS3 — Diseño y estilos (incluye el overlay de efectos).

JavaScript — Lógica del juego, drop del mate y efectos.

Canvas — Renderizado de elementos del videojuego.

Además, se utilizó como base el proyecto Full Screen Mario para la implementación del videojuego.

PROYECTO BASE

Este proyecto utiliza como referencia y base de desarrollo Full Screen Mario. Full Screen Mario es un proyecto web que recrea Super Mario Bros. utilizando tecnologías HTML, CSS y JavaScript. A partir de dicho proyecto se realizaron modificaciones y adaptaciones destinadas específicamente a esta propuesta escolar, y el juego se hizo en base al Super Mario Bros. original.

Importante: Full Screen Mario no fue desarrollado originalmente por nuestro equipo. El presente proyecto parte de dicho trabajo como base y agrega modificaciones propias para la Expotécnica.

NIVELES PERSONALIZADOS

El nivel fue creado utilizando la estructura proporcionada por Full Screen Mario, modificando elementos como la distribución del escenario, plataformas, enemigos, obstáculos, tuberías, bloques, objetos y dificultad. Se agregaron dos etapas, un checkpoint en el cartel de ESCUELA, torretas goblin y el sistema de mates para crear un desafío diferente a los niveles originales.
