SOBRE EL PROYECTO

Proyecto escolar desarrollado para la Expotécnica de 6°3, en la materia Laboratorio de Diseño Web bajo la supervisión del Profesor Pablo Gareis.

OBJETIVO

Crear un sitio web funcional dedicado a Recreo Pixelado, combinando contenido informativo sobre el juego con una versión web jugable del mismo. El protagonista es Bruno, un payaso triste, en un nivel ambientado en una escuela. Uno de los principales objetivos fue desarrollar una experiencia propia mediante la creación de un nivel personalizado.

CARACTERÍSTICAS

• Sitio web dedicado a Recreo Pixelado.

• Páginas con información relacionada con el videojuego.

• Juego completamente jugable desde el navegador.

• Nivel personalizado diseñado especialmente para el proyecto.

• Adaptación y modificación de elementos del juego.

• Funcionamiento directamente desde una página web, sin necesidad de instalar un programa adicional.

TECNOLOGÍAS UTILIZADAS

HTML5 — Estructura de las páginas.

CSS3 — Diseño y estilos.

JavaScript — Lógica e interacción.

Canvas — Renderizado de elementos del videojuego.

Además, se utilizó como base el proyecto Full Screen Mario para la implementación del videojuego.

PROYECTO BASE

Este proyecto utiliza como referencia y base de desarrollo Full Screen Mario. Full Screen Mario es un proyecto web que recrea Super Mario Bros. utilizando tecnologías HTML, CSS y JavaScript. A partir de dicho proyecto se realizaron modificaciones y adaptaciones destinadas específicamente a esta propuesta escolar, y el juego se hizo en base al Super Mario Bros. original.

Importante: Full Screen Mario no fue desarrollado originalmente por nuestro equipo. El presente proyecto parte de dicho trabajo como base y agrega modificaciones propias para la Expotécnica.

NIVELES PERSONALIZADOS

El nivel fue creado utilizando la estructura proporcionada por Full Screen Mario, modificando elementos como la distribución del escenario, plataformas, enemigos, obstáculos, tuberías, bloques, objetos y dificultad para crear un desafío diferente a los encontrados en los niveles originales.
